映译 YingYi

Windows 电影字幕翻译与视频处理工具 · 抖音电影切片一站式处理

它能做什么

  • 双语字幕烧录 — 提取电影内嵌字幕或加载 .srt，AI 翻译成中文，英文在下方、中文在上方压进画面，字号颜色可调
  • 多语言翻译 — 35 种源语言自动检测，19 种目标语言
  • 多 AI 可选 — DeepSeek / Kimi / GLM / 千问四家供应商 8 个模型自由切换，GLM-4-Flash 永久免费，各家 Key 分别保存
  • 打码 — 整屏糊掉或框选局部模糊，强度三档，时间前后可调
  • 去水印 — 框选台标、logo，全片智能抹除
  • 前方高能倒计时 — 指定时刻前，画面左下角出现 3-2-1 红色大字
  • 滤镜 — 去血色（柔和/强力）、黑白，按时间段生效
  • 切段 — 自动均分或手动切点，切口精确到帧，直接发抖音
  • 硬件加速 — Intel / NVIDIA / AMD 显卡自动检测，4K 压制飞快
  • HDR 转换 — HDR 片源自动色彩转换，画面不发灰；杜比音轨自动转通用格式

下载

GitHub Releases 下载绿色版

绿色版约 460 MB（含视频引擎与字体），解压后双击「映译.exe」即可使用。整个文件夹可拷到任意 Windows 11 电脑直接运行，无需安装任何环境。

使用步骤

  • 打开电影（mp4 / mkv 等），自动检测内嵌字幕，或手动选择 .srt 文件
  • 「设置」里选择 AI 供应商（DeepSeek / Kimi / GLM / 千问）并填写对应 API Key，字幕页选择语言后点翻译（可选 GLM-4-Flash 免费模型）
  • 按需设置打码、倒计时、滤镜、切段，所有设置自动保存
  • 点「导出」，成片自动保存到电影旁的「电影名_导出」文件夹并自动打开
